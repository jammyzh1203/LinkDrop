LinkDrop · Premiere Pro 链接素材面板
====================================

在 Premiere 里粘贴 YouTube / Bilibili / 阅流等链接，自动下载并导入项目素材箱。

安装
----
macOS：
  1. 双击「Install LinkDrop.command」。
     如果提示「无法验证开发者」：打开「系统设置 → 隐私与安全性」，
     在下方点「仍要打开」，再双击一次。
     也可以打开「终端」，把这个文件拖进去后按回车。
  2. 重启 Premiere Pro，菜单「窗口 → 扩展 → LinkDrop 链接素材」。

Windows：
  1. 双击「Install LinkDrop (Windows).bat」。
  2. 重启 Premiere Pro，菜单「窗口 → 扩展 → LinkDrop 链接素材」。

首次打开面板时，点「一键安装」下载 yt-dlp（解析与下载组件）。
需要 ffmpeg 合并高清音视频：macOS 可 `brew install ffmpeg`，
或把 ffmpeg 放到 ~/bin；Windows 放到 PATH 里任一目录。

要求：Premiere Pro 2022（22.0）及以上。

卸载：双击对应系统的 Uninstall 文件。已下载的素材不会被删除。
